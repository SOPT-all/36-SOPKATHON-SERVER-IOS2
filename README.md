## 🤙🏻 Convention 
#### Github
- Branch Strategy: Git Flow
- Branch Naming Convention : `type/#issueNumber-branchName` (ex. feat/#3-get-all-courses)
- Issue Naming Convention : `[type] name` (ex. [FEAT] 예약 내역 조회)

<br>

#### Commit
- Commit Convention: `[type]#issueNumber: commit Message` (ex. [Feat] #9: 예약 내역 조회)

| 태그 | 설명 |
| --- | --- |
| feat | 새로운 기능 추가하는 경우 |
| fix | 버그 수정 |
